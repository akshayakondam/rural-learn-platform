📚 About The Project

Rural Learn is an AI-powered gamified educational platform designed to make learning interactive, engaging, and accessible for rural students. The platform combines quizzes, mini-games, multimedia learning, AI chatbot support, voice assistance, and regional language accessibility into a single learning ecosystem.

The application provides separate dashboards for students, teachers, and parents to improve digital learning experiences and educational monitoring.
